# ITAMS Wiki

Welcome to the IT Asset Management System (ITAMS) Wiki. This wiki provides comprehensive documentation for developers, administrators, and users of the ITAMS application.

## About ITAMS

ITAMS is a comprehensive IT asset management solution built with modern web technologies including Next.js, TypeScript, and Prisma ORM. It provides multi-tenant support, role-based access control, and extensive asset tracking capabilities.
